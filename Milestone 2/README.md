# Milestone Two - Software Design and Engineering Enhancement

This enhancement focuses on improving the structure and maintainability of the Weight Tracker Android application.

The original application placed many responsibilities inside `MainActivity`. For this milestone, the project was refactored so validation, goal evaluation, SMS behavior, and data access were separated into more focused components.

## Included Files

- Enhanced Weight Tracker Android project
- Milestone Two narrative

## Key Improvements

- Improved separation of concerns
- Added dedicated validation logic
- Separated goal evaluation from SMS notification behavior
- Added repository-based data access
- Improved the goal-reached user experience
